Training-period out-of-sample home betting

Fixed: Same final selected feature specification; preprocessing and RF refitted before each season. Feature choice is retrospective, so this is not an independent selection test.

Nested: Before each season, select features by mean binary log loss in the previous two forward validation seasons; refit on all earlier seasons. No betting-return tuning.

Warmup: 2014-15 trains the first forecast. 2015-16 and 2016-17 initialize nested selection.

Historical features: Pre-match lineup history and monthly player effects may update during each evaluation season using only already completed matches; classifier refits annually.

Betting: Home only; fixed EV >0% and >2% filters; existing flat and 1-5-unit stakes. Draws count as losses. No compounding, fees or bankroll cap.

Caveat: Previously inspected audit/test seasons; unverified FIFA snapshot publication dates. Starter-based player MAP approximation with no substitution exposure or in-match segments. Partial lineups and preferred positions. Bootstrap intervals omit experiment-selection uncertainty. The candidate designs and RF hyperparameters were developed previously; nested evaluation removes future-season feature selection within this declared grid, but cannot undo prior researcher exposure to these historical seasons.
