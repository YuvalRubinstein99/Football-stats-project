Direct home-win binary classifiers

1: home win; 0: draw or away win

Direct binary logistic likelihood / random-forest log-loss classification. No goal-count fitting, no Poisson probability conversion, no class reweighting. Preprocessing fitted independently in each training fold.

Minimum mean seasonal binary log loss. Logistic C selected per candidate, then candidate per family. Fixed 0.5 threshold; ties predict home win. Choices frozen before evaluation.

Sequential pre-match features. Monthly player updates can use earlier evaluation outcomes; downstream prediction weights remain fixed throughout each evaluation season. All candidates retain the same original baseline inputs and use identical matches.

Previously inspected audit/test seasons; unverified FIFA snapshot publication dates. Starter-based player MAP approximation with no substitution exposure or in-match segments. Partial lineups and preferred positions. Bootstrap intervals omit experiment-selection uncertainty.

The no-home-win class includes both draws and away wins. This model does not separately estimate draw or away-win probabilities. Accuracy uses a fixed 50% threshold; no betting weighting, skipping, or threshold tuning is applied.
