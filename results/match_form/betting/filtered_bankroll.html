Kelly: 2% minimum expected return

Expected gross return = model probability × quoted decimal odds. The selected filter requires this to exceed 1.02: expected net return above 2%. All valid quoted decimal odds are eligible; no additional quoted-odds floor or cap is applied. The original positive-return baseline is shown for comparison.

Select the highest nominal expected-return H/D/A outcome, then apply the return filter. If that selection fails, skip the fixture. All methods use the same nominal return gate. Robust Kelly subsequently subtracts two percentage points from the selected probability. All runs start at $1,000, cap each match at 2% and each day at 10% of opening cash, and reserve stakes before same-date settlement.

Seven model families; the same frozen minimum-CV choices with and without form. 1,445 fixtures per season. No refitting or threshold search.
